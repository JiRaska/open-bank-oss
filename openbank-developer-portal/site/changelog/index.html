API deprecation changelog

The paths below continue to work during the migration window. The response headers Deprecation, Sunset and Link: rel="successor-version" carry the machine-readable notice. The sunset date is the earliest possible removal date; a path stays available while it still has live traffic.

Current deprecated API path prefixes
Path prefixNotice filed Earliest sunsetSuccessor
/api/v1/products2026-10-05 2027-07-01/api/v2/offerings

The earlier bespoke /open-banking/v2 interface is also deprecated in favor of the Berlin Group /v1 contract. Its removal remains a separate decision.

Before a deprecated path is removed

  1. Keep the notice visible and the old path serving for at least 180 days after the changelog is actually published. If publication is delayed, extend Sunset before release; the dates above are verified in CI against the notice filing date and the CI run date for a newly added notice.
  2. For each path prefix, query the owning service's Tier-B http_server_requests_seconds_count counter with its uri label covering the prefix and child routes. Require zero increase over the complete preceding 30 days, across methods, statuses and replicas. For example, the products prefix uses the selector below (substitute fees for the other row): 
    sum(increase(http_server_requests_seconds_count{namespace="accounts",service="openbank-product-catalog",uri=~"/api/v1/products(/.*)?"}[30d]))
  3. An absent series is unknown, not zero. Verify the service was scraped throughout the window, its other HTTP route counters were populated, and Prometheus retained the full 30 days (prometheus_tsdb_lowest_timestamp_seconds). Check gateway access evidence for paths that may fail before reaching the service. Record the query, UTC window, count and coverage evidence in the removal PR.
  4. Only after the window and complete zero-traffic evidence, remove the old route and its deprecation entry in the same reviewed PR. Any positive or unknown traffic resets the 30-day observation window. Keep the historical changelog entry after removal.
