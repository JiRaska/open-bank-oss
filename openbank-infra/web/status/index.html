How to read this page

SLI
A measured indicator, such as a successful public check or response latency.
SLO
An internal target for an SLI over a stated period; a target is not an observed result.
SLA
A contractual availability commitment, if one applies to a service.
Latency
Time between an external request and its response.
Recovery target
The intended time to restore a service; actual recovery is recorded in incidents.
Error budget
The permitted gap from an SLO during its measurement window.
