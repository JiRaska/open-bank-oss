# Personal data breach register (interim)

Interim register required by GDPR Art. 33(5). Procedure: `docs/runbooks/0035-personal-data-breach-notification.md`.
Every breach is entered, whether or not it was notified. **Never put personal data here**: event
identifiers, categories and counts only. No entries exist yet.
