# ADR digest — the whole decision history, one line each

_Generated by `docs/adr/gen-index.sh` — do not hand-edit._

The ADR fleet is ~400k tokens. This file is the same history in ~16k — a 25x
reduction, and the difference between 'loadable in one read' and 'not loadable at all'.
Read it in full — as a reviewer, an auditor, or an AI agent — before deciding which
ADRs to actually open. Each line is one ADR's `summary` field (see [SCHEMA.md](SCHEMA.md));
if a line does not tell you what was decided, fix that ADR's summary, not this file.

Format: **number** · title · `decision/delivery` · summary
