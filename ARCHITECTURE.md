Start with the [architecture overview](docs/ARCHITECTURE.md) for the platform context, runtime components, deployment, and security model.

Contributors can use the [architecture contributor guide](docs/architecture-contributor-guide.md) for service boundaries, cross-cutting patterns, and implementation guidance.
