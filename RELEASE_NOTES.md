# Release notes

open-bank-oss is a monorepo of ~43 independently-versioned components. Each released
component (one with its own `version.txt`, registered in
[`release-please-config.json`](release-please-config.json) +
[`.release-please-manifest.json`](.release-please-manifest.json)) keeps its own release
notes in `<component>/CHANGELOG.md`, generated by
[release-please](https://github.com/googleapis/release-please) from Conventional Commits.
See [`openbank-libs/governance/RELEASE.md`](openbank-libs/governance/RELEASE.md) for the
full release process and how it relates to the separate API-contract version axis
(ADR-0048).

Security-relevant fixes are called out under a `Security` heading in the relevant
component's changelog.

GitHub Releases (tagged `<component>-v<version>`) are the canonical, browsable source —
see the [Releases page](https://github.com/JiRaska/open-bank-oss/releases).
